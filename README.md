# Infinite Realms 2.0 — نسخه بدون پوشه

تمام فایل‌ها را مستقیماً در ریشه مخزن GitHub قرار دهید. هیچ پوشه‌ای لازم نیست.

`index.html` صفحه اصلی است و فایل‌های `main.css`، `app.js` و `state.js` را از همان مسیر بارگذاری می‌کند.

برای اجرای محلی: `python3 -m http.server 8080`؛ سپس `http://localhost:8080`.
برای تست: `npm test` (نیازمند Node.js).

این نسخه پایه مستقل است؛ قابلیت AI و ذخیره ابری هنوز پیاده‌سازی نشده‌اند. برای حفظ نسخه قبلی، فایل‌ها را در مخزن جدید یا شاخه جدا قرار دهید.
